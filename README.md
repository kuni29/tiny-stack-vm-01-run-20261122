A tiny stack virtual machine for make.fun's [tiny-stack-vm-01-run-20261122](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) bounty: one Node 22 program (`main.ts`, no dependencies) that runs every `/input/<id>/` program of the tiny stack ISA and writes `/output/<id>/stdout.bin` and `exit.txt`, faithful to the reference VM — wrapping 32-bit arithmetic, exact `Math.imul` multiplication, signed/unsigned division and shifts, and all ten traps with their exit codes. Practice set score: 1,000,000 / 1,000,000.
